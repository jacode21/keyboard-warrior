Wrong key? The first miss on a prompt is a warning strike (✕, combo resets). A second wrong key slams it onto the stack. Missed prompts land as bricks; the stack hitting the top ends the round. Hints: Tab or / (or 💡): 1st shows the modifier, 2nd the full keys; hinted clears score less. Alt KeyTips: tap Alt, release, then the letters (Alt › H › O › I). Bricks show their keys; type any brick's shortcut to sell it off the stack. Daily: same sequence for everyone today; first run is official and keeps your streak alive. Restart: R or Enter on the results screen, R while paused.

Browsers block Ctrl+N/W/T, so Ctrl+N only shows up in fullscreen mode (⛶) where the keyboard can be locked. Click the field first so it has keyboard focus.
