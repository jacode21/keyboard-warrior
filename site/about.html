The game

About

Keyboard Warrior is a free browser game that turns Excel keyboard shortcuts into a trading-floor arcade. Built for office workers who want to stop reaching for the mouse — in quick sessions between meetings.

Modes

  • Arcade — a 60-second, Tetris-style speedrun: action names fall, you type the real shortcut before they stack up. Combos, jackpots, four speeds.
  • Daily Challenge — the same seeded sequence for everyone each day, with challenge links to beat your coworkers.
  • Workflow Mode — format realistic spreadsheets (P&L, trade blotter, comps) on a simulated grid, with a live keystroke tracker, par paths and grades.
  • Keyboard Hero — a rhythm game with original, procedurally generated hip-hop beats.

Works on Windows and Mac (real Excel for Mac shortcuts), plus touch controls for phones and iPad. No accounts, no downloads — your scores live in your browser.
